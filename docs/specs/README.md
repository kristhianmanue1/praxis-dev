# Especificaciones de Praxis Dev

Las SPEC describirán comportamiento observable del CLI y la biblioteca después
de aceptar las decisiones arquitectónicas aplicables. No se crean SPEC
retroactivas para fingir que la implementación fundacional ya existe.

Cada SPEC deberá declarar su ADR gobernante, archivos cubiertos, invariantes,
errores, compatibilidad, checks y revisión de validez.
