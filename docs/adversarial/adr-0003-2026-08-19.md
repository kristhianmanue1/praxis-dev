## Hallazgos

### HA1 — La inmutabilidad de la etiqueta es declarativa (MEDIO)

El ADR dice "La etiqueta es inmutable" y "nunca se reescribe ni se borra",
pero Git permite `git tag -f`. Sin protección del lado de la forja
(GitHub protected tags / rulesets), la inmutabilidad es una promesa, no una
propiedad. Verificado: el repositorio no tiene todavía ninguna etiqueta ni
regla de protección.

**Remediación:** añadir al paso 4 la exigencia de protected tag en la forja
como parte del acto de promoción, o registrar la ausencia como riesgo
aceptado en el registro de promoción.

### HA2 — La verificación de firma no es ejecutable hoy (MEDIO)

`git tag -v <tag>` exige una clave de firma. Verificado: el entorno actual
no tiene `user.signingkey` configurada. Si el promotor no firma (HA del
mismo campo), el ADR exige declaración explícita — bien — pero el camino
"con firma" requiere preparación que el ADR no menciona.

**Remediación:** nota operativa en Confirmación: configurar firma antes de
la primera promoción, o declarar "sin firma" explícitamente.
