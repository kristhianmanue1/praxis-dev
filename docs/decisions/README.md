# Decisiones de Praxis Dev

Este directorio contiene únicamente Architecture Decision Records. El índice
definitivo será generado por `praxis adr index`; durante la fase fundacional,
los archivos se descubren por nombre y metadatos.

Estados permitidos: `draft`, `proposed`, `accepted`, `rejected`, `withdrawn`,
`superseded`, `retired`.

Los reportes, planes, incidentes, especificaciones y evidencias viven en sus
propios hogares. Un número no se reutiliza aunque la propuesta sea rechazada o
retirada.
